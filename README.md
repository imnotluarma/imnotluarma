### 🏭 What I work on

- **IIoT data pipelines** — collecting, validating, transforming, and storing machine data from industrial environments
- **Time-series databases** — InfluxDB 2/3, QuestDB, ClickHouse; schema design, ingestion, query optimization
- **Industrial automation** — Rockwell PLCs, Studio 5000, FactoryTalk Optix/View, CIP communication, signal mapping
- **ML & data pipelines** — dataset preparation, PCA, anomaly detection, TFRecord/H5/CSV/JSON handling
- **AI tooling** — n8n workflows, MCP servers, LLM-based agents for industrial monitoring
- **Infrastructure** — Docker, Linux, AWS EC2, GitLab, service orchestration
